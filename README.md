# అమ్మ-నాన్న వ్యాయామాలు · Gentle Joint Exercises

Gentle chair, standing-with-support and in-bed exercises for knee and joint pain, with animated figures,
spoken Telugu/English guidance, a weekly plan, rest timers and a progress calendar.

**Install on a phone**
- Android (Chrome): open the site → ⋮ menu → *Install app* (or tap the *Install app* button in the top bar).
- iPhone (Safari): open the site → Share → *Add to Home Screen*.

The app works offline after the first visit. Progress and notes stay on each phone.

Please check with a doctor before starting any exercise.
